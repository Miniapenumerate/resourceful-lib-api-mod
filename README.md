# Resourceful Lib — Multiplatform Utility API

[![Download Latest](https://img.shields.io/github/v/release/Miniapenumerate/resourceful-lib-api-mod?style=flat-square&label=Download&color=brightgreen)](https://github.com/Miniapenumerate/resourceful-lib-api-mod/releases/latest)
[![Forge](https://img.shields.io/badge/Loader-Forge-orange?style=flat-square)](https://files.minecraftforge.net/)

A cross-platform library providing utilities for config, networking, and registries for Team Resourceful mods.

![Resourceful Lib — Multiplatform Utility API Preview](https://cdn.modrinth.com/data/G1hIVOrD/52130f41d05162ce6d7d1832a47d3c238d102632_96.webp)

## Features

- Cross-platform config system with GUI integration
- Networking utilities for client-server synchronization
- Registry wrappers compatible with Forge and Fabric
- Used by Sophisticated Backpacks and Storage
- Lightweight with near-zero performance overhead

## Installation

1. Install [Minecraft Forge](https://files.minecraftforge.net/) for your Minecraft version
2. Download the JAR matching your exact Minecraft version above
3. Place the JAR into your `.minecraft/mods/` folder
4. Launch Minecraft with the Forge profile

## Requirements

- **Mod Loader:** Forge
- **Minecraft:** See download table above
